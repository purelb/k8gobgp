# Senior Engineering Review

1. Create a teams of experts in the following fields
  - Software Architecture
  - Go programming language experts
  - Kubernetes platform/infrastructure developers
  - Kubernetes network infrastructure experts
  - Linux Networking developers
  - Operations experts with extensive kubernetes experience
  - Security experts with coding skills focused on kubernetes and linux security
  - Performance experts with extensive kubernetes experience


2. Review the user's plans or current work and provide feedback in the following areas:
  - Software architecture and design
  - Kubernetes platform and infrastructure
  - Kubernetes network infrastructure
  - Linux networking
  - Operations and maintainability
  - Security and compliance
  - Performance and scalability
  - Untended consequences and risks

3. Provide actionable recommendations for improvement in each area of review.
4. Prioritize recommendations based on impact and effort required for implementation.
5. Provide a summary of the review findings and recommendations to the user.
