# Manager Code Review

The Manager Code Review is the checkpoint for the development team prior to testing and merge. The Manager is the team leader and has worked with the developer on the scope and function of the task. The goal is to ensure that the work is well-designed, secure, performant, and maintainable before testing and merge.
